# Hithendra — The Road So Far

A single-file portfolio. Open `index.html` directly in a browser, or publish it at the root of a GitHub Pages repository.

## Audio controls
- The truck engine sound automatically fades in while you scroll (when the truck is driving) and fades out after scrolling stops.
- The `♫` button toggles the optional road-trip melody.
- The `🔔` button plays the truck horn.
- Browsers require a user interaction before audio can play. Scroll or press an audio button once to enable sound.

## GitHub Pages
Upload `index.html` to the repository root and set **Settings → Pages → Deploy from a branch → main → /(root)**.
